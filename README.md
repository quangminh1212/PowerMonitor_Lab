# Power Monitor Lab

Power Monitor Lab is a project scaffold for measuring and tracking the electrical power and energy use of devices connected to a computer.

## Project goal

The project aims to show instantaneous power in watts (W), record readings over time, and summarize energy use in watt-hours (Wh) or kilowatt-hours (kWh).

## Measurement accuracy

Accurate readings depend on the hardware exposing trustworthy power telemetry. Many connected devices do not report their actual power draw to the computer, so an external meter or supported sensor may be required. Any estimate should be labeled as an estimate rather than a measured value.

## Planned capabilities

- Read power data from supported sensors or meters.
- Record timestamped measurements.
- Calculate energy use from readings over time.
- Show usage history and summaries.
- Distinguish measured values from estimates and unsupported devices.

## Current status

This repository currently contains the project README only. The application and measurement integrations have not been implemented yet.
